# Data attribution

Contains modified Copernicus Sentinel data 2026.

The small Sentinel-2 RGB images in `web/observations/` are display previews derived from acquired Sentinel imagery using a fixed 0–0.3 reflectance stretch and gamma 2.2. They are visual context only, not classifications. Copernicus Sentinel data is available for free, full and open use subject to its [legal notice](https://sentinels.copernicus.eu/documents/247904/690755/Sentinel_Data_Legal_Notice).

Other sources include Copernicus DEM, © OpenStreetMap contributors (ODbL) with historical extraction through HeiGIT/ohsome, Copernicus EMS reference products used only for evaluation, and Qwen/Qwen3-0.6B (Apache-2.0). Refer to the final report for acquisition dates, source URLs, quotas, cost limits, and evaluation boundaries.

Evaluation-only EMSR GRA GeoPackages are not distributed here; their registered filenames and SHA-256 digests are retained in docs/dataset-readiness.json.
